# Security policy

This repository contains educational notebooks and does not provide a network service. Please do not include credentials, private datasets, unpublished student work, or access tokens in notebooks, outputs, issues, or pull requests.

For a security-sensitive report, email [roohie@umass.edu](mailto:roohie@umass.edu) instead of opening a public issue. For numerical or physical discrepancies, use the public scientific-discrepancy issue form.
